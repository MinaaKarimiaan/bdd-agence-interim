# Agence d'Intérim – Conception et implémentation d'une base de données

Projet académique réalisé dans le cadre du Master 2 MIASHS à l'Université Grenoble Alpes (2025/2026).

## Description

Conception et implémentation d'une base de données relationnelle pour la gestion d'une agence d'intérim : candidats, offres d'emploi, entreprises, candidatures et salariés.

## Contenu du dépôt

- `database_create.sql` – Création des tables, contraintes et triggers
- `database_data.sql` – Insertion des données de test
- `database_queries.sql` – Requêtes SQL (10 requêtes)
- `database_triggers.sql` – Tests des contraintes et triggers

## Fonctionnalités

- Modélisation relationnelle complète (MCD/MLD) normalisée en 3NF
- Requêtes SQL avancées : jointures, sous-requêtes, agrégations, division relationnelle
- Triggers : suppression interdite, date de fermeture automatique, vérification de l'âge, disponibilité
- Procédure stockée : remise à disposition automatique des candidats en fin de contrat

## Technologies

MySQL 8 · MySQL Workbench
